# Морьтон Эмч — iPhone апп (SwiftUI)

Вэбийг дотроо ачаалдаг хуучин хальс (`mobile/`) биш — өөрийн дэлгэцтэй жинхэнэ апп.
Вэбтэй **ижил Firestore сан**-г уншиж бичнэ.

## Суулгах (нэг команд)
iPhone-оо кабелиар Mac-д холбоод Terminal-д:
```
bash <(curl -fsSL https://raw.githubusercontent.com/Moriton-tech/Moriton/v2/ios/install.sh)
```

## Юу байгаа (v0.5)
- Нэвтрэх — вэбийн хэрэглэгч, нууц үгээр
- Доод цэс: **Нүүр · Миний ажил · Байрлан · Шинжилгээ · Би**
- **Нүүр** — «Одоо хийх» жагсаалт (буцаагдсан онош, дараагийн адуу, бичээгүй эмчилгээ, мэс засал), өнөөдрийн тоо, сүүлийн 7 хоногийн график
- **Миний ажил** — Хүлээлт · Даалгавар · Түүх
- **Миний KPI** — үзлэг, хамтарсан, төлөвлөгөөт, адуу, үйлчилгээ, байрлан эмчилгээ, ажилласан өдөр, дундаж хугацаа; ачааллын график; мөнгөн дүнгүй
- **Профайл зураг, тохиргоо** — зураг (`profiles` collection), мэдэгдлийн төрөл бүрийг асаах/унтраах
- **Эмчилгээ бичих** — вэбийн өдрийн бичлэгтэй ижил: T/P/R/жин, цаг, тэмдэглэл, онош, үйлчилгээ, эм (тоо × нэгжийн үнэ), курсийн эм автоматаар, өдрийн дүн. Сүлжээгүй үед утсанд хадгалж, холбогдмогц илгээнэ
- **Үзлэг хийх** — хүлээлтээс адуу авч үзлэг бөглөөд дуусгана. Вэбийн `finishExam()`-тай ижил бичлэгүүд (үзлэг, нэхэмжлэх, шинжилгээний захиалга, лог, хүлээлтээс хасах) нэг багцаар бичигдэнэ. Дууссаны дараа зураг оруулна
- **Миний үзсэн адууны түүх** — өөрийн хийсэн, хамтарсан бүх үзлэг; хайх, дэлгэрэнгүй, зураг нэмэх
- **Хүлээлт**, **Байрлан**, **Шинжилгээ** — харах
- **Зураг авах** — үзсэн адуу болон байрлан эмчлүүлж буй адууны зураг; вэбийн үзлэгийн зурагтай нэг дор хадгалагдана
- **Жижүүр эмч** — тухайн өдөр жижүүрээр сонгогдсон бол жижүүрийн мэдээ бичих, ээлжээ дараагийн эмчид хүлээлгэн өгөх / хүлээн авах (шинэ `duty` collection)
- **Би** — энэ сарын өөрийн үзүүлэлт, ажлын хувиар
- Мэдэгдэл — 17:00-д бичээгүй даалгаврын сануулга (утас өөрөө); серверийн мэдэгдэл доорх алхмын дараа

## Одоохондоо байхгүй
- Үзлэгийн хуудас хэвлэх, бичлэг засах/устгах, адуу гаргах, эзэнтэй ярьсан тэмдэглэл, маргаашийн төлөвлөгөө — компьютер дээрээс
- Сүлжээгүй үед үзлэг дуусгах (бичих боломжтой, дуусгахад сүлжээ хэрэгтэй)
- Жижүүрийн мэдээ, ээлж хүлээлцэлтийг вэб дээр харах (одоогоор зөвхөн апп дотор)
- Хэрэглэгч бүрийн жинхэнэ нэвтрэлт (v2-ын «суурь» ажил) — эмч нарт тараахаас өмнө заавал

## Мэдэгдэл (push) асаах — нэг удаа
Илгээгч нь `functions/` (Firebase Cloud Functions). Бодит орчинд хараахан туршаагүй.
1. Firebase Console → moriton-4ecc0 → **Blaze** төлөвлөгөө (Cloud Functions-д шаардлагатай)
2. Apple Developer → Keys → APNs түлхүүр (.p8) + Key ID. CleanGo-д үүсгэсэн түлхүүр ижил багийнх тул дахин ашиглаж болно
3. Mac Terminal, репогийн хавтаст:
   ```
   firebase functions:secrets:set APNS_KEY_ID
   firebase functions:secrets:set APNS_KEY_P8
   cd functions && npm install && cd .. && firebase deploy --only functions
   ```
   Бүсийн алдаа гарвал: `functions/index.js` дахь `REGION`-г алдаанд заасан бүсээр солино.
4. Апп → **Би** таб → «Мэдэгдэл: Бүртгэгдсэн» гэж гарсан байх ёстой

Мэдэгдэл ирэх үйл явдал: адуу хуваарилагдах · хүлээлтэд шинэ адуу · онош буцаагдах · шинжилгээний хариу гарах · ээлж хүлээлгэн өгөх / хүлээн авах.

## Вэбтэй давхардсан логик — анхаар
Үйлчилгээ / эм / шинж тэмдгийн үндсэн жагсаалт `app.js`-ээс хуулагдаж `MoritonEmch/catalog.json`-д ордог.
Вэб дээр `SVCS`, `MED_LIST`, `SYMPTOM_LIST` өөрчлөгдвөл: `node ios/scripts/gen-catalog.js` ажиллуулаад аппыг дахин суулгана.
Үнэ, нэмсэн/хассан үйлчилгээ, шинжилгээний тохиргоо, хуудасны дугаарын тохиргоог апп `clinic_config`-оос шууд уншдаг тул тэдгээр нь автоматаар таарна.
Үзлэг дуусгах логик (`Store.swift` → `finishExam`) нь вэбийн `finishExam()`-ын хуулбар — вэб талд өөрчилбөл энд ч өөрчилнө.

## Зарчим
Апп дотор хийдэг ажил бүр вэб дээрх тэр ажлаас **дутуу талбаргүй** байна (үзлэг, өдрийн эмчилгээ).
Аппад хараахан ороогүй ажлууд вэб дээр хэвээр хийгдэнэ — дээрх «Одоохондоо байхгүй» жагсаалт.
